# 魏嘉个人求职作品集

面向内容运营 / 新媒体运营 / 内容策划 / 创意运营方向的个人作品集网站。

## 技术栈

- Vite
- React
- TypeScript
- Tailwind CSS

## 页面

- 首页
- 关于我
- 作品集
- 技能
- 探索与学习

## 核心组件

首页 Hero 组件位于：

```text
src/components/CreativeArchiveFolderHero.tsx
```

作品数据位于：

```text
src/data/projects.ts
```

## 本地运行

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

构建：

```bash
npm run build
```
